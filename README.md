SOLFEED – The Social for the Real Ones

SolFeed is a fully on-chain social layer built on Solana.  
It is sovereign, censorship-resistant, and designed for those who no longer obey.

Every post, every like, every comment lives on-chain, owned by no server, no admin, no algorithm.

## Why SolFeed?

- 100% on-chain — no off-chain tricks, no IPFS hiding truth
- Real fees, real value — every action pays the creator
- Immutable usernames — no identity theft, no fakes
- Verification via X (Twitter) — paid, permanent, public
- Follow, unfollow, like, post, comment — all provable, all open

## Tech Stack

- **Solana** – ultra-low fees, ultra-fast
- **Anchor** – battle-tested framework for Solana smart contracts
- **On-chain images** – profile and post images are stored in real bytes, no links
- **No backend** – all logic lives on Solana

## Fee Structure

| Action                  | Tariff (paid by user) 
|-------------------------|------------------------
| Create profile          | 0.0025 SOL            
| Update bio/image        | 0.0020 SOL             
| Like / Comment / Follow | 0.00025 SOL        
| Post (text only)        | 0.00025 SOL            
| Post (with image)       | 0.00030 SOL            
| Verify via X            | 0.1 SOL (one-time)     
| Unfollow                | Refund: 50% user / 50% creator
